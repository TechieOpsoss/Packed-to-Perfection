# Feed Me, Earthling!

Capstone project for the Game Studio Roles and Development course at the University of Washington.

​Click and drag to fit food items into alien cafeteria trays to fulfill their needs, lest you yourself become their lunch.

## CONTROLS

- Pick up - Left Click

- Rotate - Q/E/R/Right Click/Middle Click/Scroll

## BUILDING

Open folder with the Godot editor and use Project -> Export -> Export All... to build runnable Linux, Windows, and Web builds to the ./Build directory. (It may be necessary to create the directory at ./Build/WebGame in order for the Web build to succeed).

Run 'make' in the ./Build directory to upload builds to the Itch.io game sharing platform (requires Itch.io's Butler program installed on the CLI).
